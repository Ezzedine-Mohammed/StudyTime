# StudyTime

Browser extension for managing study sessions and reducing distractions.

> **Status:** Under development. The popup interface is being built; extension functionality is not yet implemented.

## Planned Features

- Study sessions with a timer and pause/resume controls
- User-defined distracting website blocklist
- Session summaries and basic study statistics

## Project Structure

- `extension/` — browser extension files, including the popup UI, assets, and manifest
- `.stylelintrc.json` — Stylelint configuration
- `package.json` — development tooling and scripts

## Current Development Stage

The popup UI is a work in progress. The `extension/manifest.json` file has not been configured yet, so the extension is **not ready to load into a browser**.
